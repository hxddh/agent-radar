## English

### 1. Executive Summary
- This week's biggest change: platform vendors pushed hosted/managed agent paths further into the mainstream (Microsoft Foundry hosted agents + dev pack; Cloudflare agents@0.34.0 exporter changes; BrowserStack MCP server), concentrating artifact export/retention risk at vendor-defined endpoints.

- Most important user experience signal: multiple operator field reports and vendor notices (Cursor extension compromise; social reports of sandbox escapes / "agent goes blind" after git push) show real-world fragility around workspace persistence, connector scopes, and extension supply-chain—operators are being forced to adopt pre-upgrade snapshotting and tighter connector ACLs.

- Most important infra signal: MCP proliferation and first-party MCP server packages (BrowserStack @browserstack/mcp-server + many MCP routers) lower integration friction but increase routing/fragmentation risk (more endpoints to govern).

- Most important storage implication: vendor-hosted exporters and shared KV caches are becoming first-class artifact sinks; map vendor exporter endpoints, TTLs, and per-tenant ACLs into retention & forensic runbooks now.

- Biggest uncertainty: monetization & long-running pricing models remain fragmented (seat/token/task/compute signals mixed); this shapes what workloads move off-IDE versus into cloud task runners.

## 中文

### 1. Executive Summary
- 本周最大变化：平台厂商加速托管/管理型 agent 路径（例如 Microsoft Foundry 托管 agent、Cloudflare agents@0.34.0 的导出改动、BrowserStack 发布 MCP server 包），因此产物导出与保留风险更多落在厂商端点上。

- 最重要的用户体验信号：Cursor 扩展安全通告、社区关于沙箱绕过与 "push 后 agent 丢失上下文" 的现场报告，表明工作区持久化、连接器权限与扩展供应链是实际故障点，运维侧开始普遍采用升级前 snapshot 与更严格的连接器 ACL。

- 最重要的基础设施信号：MCP 服务器与路由器数量增加（厂商/第三方实现并存），既降低了接入门槛，也增加了治理与碎片化风险。

- 最重要的存储启示：厂商导出端点与共享 KV 缓存已成为主要的产物寄存面，运维必须把厂商导出端点、TTL 与租户 ACL 纳入保留与取证流程。

- 最大不确定性：长期运行 agent 的价格模型仍然分散（按座位/按 token/按任务/按计算时间皆有信号），这决定了哪些工作负载会从 IDE 移向云端任务运行器。
