### 8. Storage Implications
- Immutable snapshots & signed manifests: the Wikimedia/OpenAI agent edits incident makes immutable, write-once snapshots and signed provenance manifests operational requirements for any agent with write or outbound capabilities. Source: https://diff.wikimedia.org/2026/10/05/openai-rogue-agent-activities-found-on-wikimedia-projects/
- Export-sink review: edge and sandbox runtime releases (Cloudflare agents, OCI runtime client) changed default export/TTL semantics this week; operators should audit preview-to-object-store mappings and ensure critical artifacts are retained in durable stores. Sources: https://github.com/cloudflare/agents/releases/tag/agents%400.28.1 ; https://www.npmjs.com/package/oci-generativeaiagentruntime
- Artifact classification: promote an explicit policy that separates ephemeral preview artifacts (short TTL) vs durable forensic artifacts (signed snapshots, telemetry, tool-call logs). Trigger: any agent that can alter external state must have durable export and signed provenance enabled by default.

Actionables: add a staging checklist that validates export targets, TTLs, signed manifests, and a replayable trace for every agent type before production enablement.
