- This week's biggest change: Multiple mainstream vendors shipped persistent/always-on agent primitives (OpenAI Dots + Agents API) while concurrent incident and field reports (training/eval probes, DNS egress anecdotes) elevated containment and egress controls as the operational priority.

- Biggest uncertainty: Pricing and commercial packaging for long-running agents (seat vs. task vs. compute) remains fragmented; no clear market signal this week.

### 3. Mainstream Agent Progress

- Always-on / persistent assistants are now mainstream product surface (OpenAI Dots + continued vendor launches). This materially affects artifact lifecycles (snapshots, scheduled outputs) and forensic expectations.
- Runtimes and IDE integrations (Claude Code, OpenAI Codex CLI, JetBrains Air, Vercel sandbox updates) continue to harden; upgrades often change default containment and egress semantics.
- Observability/eval: Langfuse release (v4.50.0) and broader telemetry tooling are improving trace-level retention and chargeback modeling for agent runs.

### 4. Emerging Agent Progress

- MCP SDKs v2.3.0 and multiple MCP server/router projects continue to appear (increasing connector portability). Evidence: modelcontextprotocol SDK releases (Strong) and router projects observed in screening.
- Edge/preview sandboxes (Cloudflare agents@0.26.0, Vercel sandbox improvements) extend runtime surfaces, enabling lower-latency agent work but adding export/preview sink complexity.

### 5. User Experience

- Field reports (Reddit / Bluesky) show two operational pain points: (1) MCP connector regressions after containment/upgrade events; (2) anecdotal DNS-based egress during unisolated runs. Both are Medium-strength social evidence that drive concrete operator mitigations (see Playbook updates below).
- Taskflow Agent (GitHub Security Lab) shows a pattern for embedding agentic fuzzing into CI (Strong); useful pattern but generates large ephemeral artifacts and needs isolation.

### 6. Useful Tricks

- Connector contract tests: add a minimal handshake/tool-call test that runs against a pinned staging runtime as a blocking gate for runtime upgrades (promote to Playbook actionable item).
- DNS telemetry: log and monitor DNS queries from agent hosts, use authenticated resolvers and anomaly alerts to catch non-HTTP exfil channels.

### 7. Infrastructure Changes

- MCP proliferation + MCP SDK updates reduce integration friction but raise fragmentation risk as vendors ship their own server implementations and router projects.
- Sandboxes scale patterns: Modal and Daytona posts demonstrate primitives for rapidly provisioning isolated sandboxes at scale (Modal claims scaling patterns for many concurrent sandboxes). These primitives make large-scale fuzzing and CI-based agent testing viable but increase short‑term storage/telemetry load.

### 8. Storage Implications

- Persistent agents (Dots) require new retention classes: agent-state snapshots, scheduled-output archives, and long-window telemetry. Operators must add lifecycle rules and scrubbing/export hooks.
- Preview/export flows (Cloudflare, Vercel) should map to short-TTL buckets by default; observability traces to durable indexed stores for incident investigations.

### 9. Commercialization

- No clear pricing consensus for long-running agents (seat vs. token vs. compute time). Vendors are experimenting; operators should budget for both storage and telemetry costs in addition to compute.

### 10. Enterprise Adoption

- Microsoft Foundry Routines GA and Cloudflare observability features are two vendor moves that increase enterprise readiness by adding policy/evidence surfaces enterprises can anchor to their governance flows.

### 11. Reliability and Evaluation

- Eval/telemetry platforms (Langfuse) continue to mature; recommended to instrument agentic runs to capture both tool-call traces and artifact volumes for TCO calculations.

### 12. Security and Governance

- Containment and egress are the top operator priorities this week: vendor containment posts + field DNS egress anecdotes raise the urgency of egress control, artifact classification, and quick rollback staging practices.
- Supply-chain and extension risks persist (malicious packages, extension RCE); continue to enforce extension signing and pinned-bundle sourcing.

### 13. Ecosystem Standards

- MCP patterns are converging into many SDK/server/router releases; absent an interoperability governance body this looks set to fragment by implementation even as the protocol idea gains adoption.

### 14. Anti-Signals

- Pricing signals for long-running agents are scattered; no single vendor established a dominant billing model this week.
