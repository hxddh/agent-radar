## English

### 1. Executive Summary

- Biggest thesis change: platform-vendor MCP adoption and containment/security moved sharply higher this period. Multiple vendor product deltas (OpenAI ChatGPT Wallet, Anthropic Projects parallel-workers, Cloudflare pentest guidance) and real marketplace compromises (Cursor) increased operational urgency.
- Strongest product signal: OpenAI ChatGPT Wallet (agents can now initiate payments); evidence: OpenAI product page + Reuters. Operational surface: billing, audited receipts, webhooks, and new privileged actions for agent sessions.
- Strongest user-experience signal: IDE+extension vectors broaden attack surface — Open-VSX listings (OpenAI ChatGPT VS Code extension) and confirmed malicious marketplace extension variants (Cursor incident) show high operator impact at developer endpoints.
- Strongest infrastructure signal: GHSA advisories (Claude Code TOCTOU; mem0 cross-tenant leak) plus Cloudflare guidance on AI pentesting elevate containment, tenant isolation, and exporter→object-storage mapping as immediate operator tasks.
- Strongest storage implication: object storage and exporter/default retention mapping are now primary forensic/leakage considerations (Cursor canvases, Grok Build uploads, Cloudflare exporter TTL changes).
- Biggest anti-signal: vendor runtime churn (frequent SDK/pre-release cadence for openai/codex and Anthropic runtime patches) makes wholesale, immediate standardization or hard-mandate upgrades impractical for many operators.

### 1. Executive Summary
